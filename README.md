# Dashboard Admin

Dashboard Admin is a modern web-based admin panel designed to help manage and monitor application data through a clean and interactive interface. This project was built to practice frontend dashboard development, API integration, and data visualization using modern React technologies.

The dashboard provides several management pages such as users, products, analytics, and activity tracking. It also includes charts, tables, responsive layouts, and dynamic routing to simulate a real-world admin system.

---

## Project Purpose

This project was created to improve skills in:

- React & TypeScript development
- Component-based UI architecture
- API integration
- State and server data management
- Responsive dashboard layout design
- Data visualization using charts
- Building fullstack applications with separate frontend and backend

## Installation

### Frontend Setup

Clone the repository:

```bash
git clone https://github.com/DwiyashantaEidelS/dashboard-admin.git
```

Go to project folder:

```bash
cd dashboard-admin
```

Install dependencies:

```bash
yarn install
```

Run development server:

```bash
yarn dev
```

Frontend runs on:

```text
http://localhost:5173
```

---

### Backend Setup

Clone backend repository:

```bash
git clone https://github.com/DwiyashantaEidelS/dashboard-admin-backend.git
```

Go to backend folder:

```bash
cd dashboard-admin-backend
```

Install dependencies:

```bash
yarn install
```

Run backend server:

```bash
yarn start
```

Backend runs on:

```text
http://localhost:8800
```
