# Dashboard Admin

Modern Admin Dashboard built with React, TypeScript, Vite, SCSS, Material UI, and Recharts.

## Features

- Responsive admin dashboard UI
- Data table with sorting and filtering
- Charts and analytics
- User & product pages
- React Router navigation
- React Query data fetching
- Mock backend API

## Tech Stack

- React
- TypeScript
- Vite
- SCSS
- Material UI
- Recharts
- React Query
- Node.js Backend API

## Installation

Clone the repository:

```bash
git clone https://github.com/DwiyashantaEidelS/dashboard-admin.git
```

Go to project folder:

```bash
cd dashboard-admin
```

Install dependencies:

```bash
yarn install
```

Run development server:

```bash
yarn dev
```

Frontend runs on:

```text
http://localhost:5173
```

---

# Backend Setup

Clone backend repository:

```bash
git clone https://github.com/DwiyashantaEidelS/dashboard-admin-backend.git
```

Go to backend folder:

```bash
cd dashboard-admin-backend
```

Install dependencies:

```bash
yarn install
```

Run backend server:

```bash
yarn start
```

Backend runs on:

```text
http://localhost:8800
```
